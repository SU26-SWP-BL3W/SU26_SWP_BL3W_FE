# Agent Customization Rules

## MANDATORY WORKFLOW: ANALYZE AND CONFIRM BEFORE ANY CODE EDITS

1. **Analyze First**: When the user reports an issue, provides screenshots, or requests a fix, ALWAYS inspect and analyze the problem thoroughly first.
2. **Present Analysis & Plan**: Present the detailed analysis of the root cause, exact technical findings, and proposed changes to the user.
3. **Obtain User Approval**: DO NOT make any code edits or modify files until the user reviews the analysis and explicitly approves proceeding.
